# homebrew-tap

Homebrew tap for [jindrichskupa](https://github.com/jindrichskupa)'s tools.

## Install

```bash
brew install --cask jindrichskupa/tap/franta
```

Or tap first, then install:

```bash
brew tap jindrichskupa/tap
brew install --cask franta
```

## Available

| Cask     | Description                          | Source |
|----------|--------------------------------------|--------|
| `franta` | Terminal UI for Apache Kafka         | [jindrichskupa/franta](https://github.com/jindrichskupa/franta) |

## Notes

Casks in `Casks/` are generated automatically by
[GoReleaser](https://goreleaser.com) on each upstream release — do not edit by
hand.
